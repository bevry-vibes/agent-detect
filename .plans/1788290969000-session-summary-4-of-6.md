**Gotchas hit this conversation**:
- Zig 0.16: context-typed tagged-union shorthand `.tag(payload)` is a compile error ("type ...tag_type.?' not a function") — must write `.{ .tag = value }` in a typed position; bare tags (`.pipe`, `.ignore`) are fine
- `std.Io.Dir.readFileAlloc` limit arg is `Io.Limit` (`std.Io.Limit.limited(n)` or `@enumFromInt(n)`)
- Killing a process whose cmdline matched my own search string (my pwsh query contained "fixtures capture") killed my own shell mid-command (exit 255) — harmless, but beware
- PowerShell `Set-Content`/`WriteAllLines` rewrites LF files as CRLF (AGENTS.md trap) — the `-p` insertion script detected line endings (`$raw -match "\r\n"`) and trailing-newline state, and wrote back with the original via `[IO.File]::WriteAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))`; result: `inserted: 126  crlf: False  endsNewline: False`, diff = exactly 126 added `"-p",` lines + legitimate daemon ledger churn
