## Strategy & Approach

- **Daemon stopped before any index.json edit** (it re-saves index.json and would clobber edits). Still stopped.
- **Redaction design**: `<project>` = the worker's own cwd at capture time (the OS temp workdir), computed via `currentPathAlloc` inside the capture process — so it works for daemon-side from-identity runs too (repo cwd) and for any harness worker. Project pass before home pass; backslash boundary accepted everywhere; all remaining backslashes normalized to `/` in the final string (fixtures read cleanly cross-platform). Ownership: `slashifyOwned` takes ownership to avoid leaks (the test allocator caught one).
- **Env-var over CLI flag for the fixtures root**: the capture command is what the *model* runs from the prompt; an env var (`AGENT_DETECT_FIXTURES_DIR`) inherited by the harness's shell is invisible and un-droppable, whereas a flag the model must reproduce is fragile.
- **Pin semantics**: pin to the catalog id the detector can resolve (last-slash segment folds to the rule name); where the catalog no longer serves the combo (cerebras/qwen3, groq/llama-4), pin the abstract-grid id so the failure is a fast, honest "model not found" instead of silently consuming the user's default model (proven twice: kilo and opencode both defaulted to hyper's `glm-5.3-flash`).
- **Pin insertion is line-anchored** (key-line → `"prompt_invocation": [` → binary → `"run",`), never a jq roundtrip — preserves the file's hand formatting, LF endings, and no-trailing-newline.
- Commit discipline: build + `zig build test` before committing; trailer via `./zig-out/bin/agent-detect.exe trailer co-author` (→ `Co-authored-by: Crush · Qwen3.8 27B <crush-chutes-qwen3827b@local>`); no em-dashes in new source (use commas/periods/parens/semicolons).
