## What's changed since 2026.8.11-3

The largest release to date: the fixture store was redesigned twice, detection grew a Windows path, and the rule tables learned to fold release stamps and providers.

### Detection and rules

- Added the zcode desktop harness, and the Ollama and Cloudflare Workers AI providers.
- Added the Chutes TEE and OpenCode Go rules, a `model_license` field, and the folding policies for provider spellings.
- Model ids shed their whole namespace: release-date stamps (`-0731`, `-2507`) fold into the base rule as variations instead of creating a second model.
- Qwen3-32B and Qwen3.6-27B (with the Chutes TEE variations) resolved the last `unknown_models` entries.
- Added OpenRouter-maintained evergreen snapshots for model and provider discovery, refreshed on a schedule.

### Fixtures and the store

- Split the fixture channels into from-identity declarations and from-capture records, with a per-channel store and an outputs/meta envelope.
- Converted the store to `fixtures/index.json`: one committed file replaces the SQLite queue and error ledger, with the pop protocol, the filter axes, and a backlog for retryable failures.
- Captures are written on success only; a partial capture fails instead of writing incomplete meta.
- Migrated to per-channel folders with dash-normalised names and no dot prefixes.

### Windows

- Added Windows session-store detection and the `ps1`/`cmd` shim probe names, and set the console to `CP_UTF8` at startup.
- Added the harness-config hard rule: agent-detect reads harness configuration and never writes it.

### Sources and tooling

- Split `main.zig` into `rules.zig`, `core.zig`, and `dev.zig`, with `binary_names` unified across the surfaces.
- Improved the capture daemon: streamed worker output, a killed process tree on timeout, portable evidence paths, and workers that run from an empty temp directory.
- Drained the first Darwin and Linux sweeps, and authored the 151 missing Darwin invocations of record.
