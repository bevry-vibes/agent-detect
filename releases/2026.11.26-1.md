## What's changed since 2026.11.23-1

### OpenCode session attribution

- `OPENCODE_SESSION_ID` is now resolved before the cwd fallback, in both the v2 session store and the legacy store. Multiple sessions can share a directory, and running `agent-detect` from another directory could attribute the shell to a different session's model.

### Daemon stability

- The daemon's damped-capture set now keeps its fixture-id keys on the long-lived arena. The key previously pointed into the iteration arena, which is reset on the next idle tick, so a failed capture could leave a dangling key. The crash fix duplicates the id before the worker stores it.

### Windows and tooling

- `scripts/zig.ps1` keeps the native exit code when probing `zig version`; the pinned compiler is no longer re-downloaded on every run.
- `site/tools/build_data.ts` uses `fromFileUrl`, so Windows paths resolve and `deno task data` no longer fails there.
- The harness installer recognises the OpenCode desktop NSIS path on Windows and probes Appx packages through Windows PowerShell when PowerShell 7 cannot load the Appx module, fixing `-Check` and version reports.

### Fixtures

- Regenerated 1,209 from-identity declarations across the installed harnesses and captured 16 free Windows fixtures.
- Regenerated seven OpenCode free-model captures on Linux, including five new combos.
- Pruned the ended OpenCode Console free ids (`glm-5.3-flash`, `longcat-2.5`, `tidepool-alpha`) and the stale OpenCode Go `longcat` id, and added the served free-id variations for Gemma 4 31B and Nemotron 3 Ultra.
- Recorded the pi/OpenRouter credential failure and the missing `opencode-go` Hy4 Flash invocation in the backlog rather than working around them.

### Rules

- ERNIE 5.5 Flash Preview is recorded as Apache-2.0 open-weight. The Preview weights landed on Hugging Face on 23 November under Apache-2.0; the Base model keeps Baidu's own terms. The rule's sources now point at the Preview repository and its licence.
- GLM-5.4 is noted as available to the GLM Coding Plan and ZCode from 23 November. Its weights are still promised, not published, so openness and licence remain unset. The `glm-5.4[1m]` context spelling is folded into the same rule.
- The generated index data is refreshed with both rule changes.
