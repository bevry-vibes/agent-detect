## Initial release

The first release of agent-detect: a single-file Zig CLI that reads what a machine already knows about the agent running on it and prints the harness, provider, and model.

### Detection

- Added the detection tool itself, with harness rules for the agents in use at the time, including Goose, Kimi Code, and MiniMax Code.
- Declared the rules as data: harnesses, providers, and models resolve through one table each, so a new surface is a rule rather than a branch.

### Foundations

- Scaffolded the repository with the Bevry skills, licence, and base configuration.
- Added `DESIGN.md` with the project's trade-offs, and `AGENTS.md` pointing agents at the skills rather than copying them in.
